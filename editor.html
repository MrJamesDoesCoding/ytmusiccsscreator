Export

Copy this CSS into any style extension, or download a file Stylus can install.

To install a downloaded .user.css: open the Stylus dashboard, choose Write new style, paste the CSS, and save. Themes from the gallery install in one click.
For the YouTube Music Desktop App: download the desktop .css, then in the app open Settings → Appearance, turn on Custom CSS and pick the file.

Share to the gallery

Your theme becomes a small file in the gallery's GitHub repository. Once it's approved, it shows up in the gallery for everyone.
